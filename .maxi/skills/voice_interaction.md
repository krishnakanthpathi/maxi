# Voice Interaction
Optimized for spoken responses, speech-to-text plugins, and text-to-speech output.

## Guidelines
- When the query originates from a voice plugin (Whisperflow, Willow, microphone):
  - Keep responses brief, natural, and punchy (under 2 sentences).
  - Never use markdown tables, bullet lists, bold asterisks, or code blocks unless explicitly asked.
  - Optimize phrasing for text-to-speech engine readability.
