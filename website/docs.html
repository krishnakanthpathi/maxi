Two pieces. One assistant.

The Python daemon handles voice, models, and tools. The native macOS HUD is its floating companion. They ship separately: the installer installs the Python wheel first, then the native app. Opening Maxi starts the backend and checks its health before the HUD connects.

01 / GET UP AND RUNNING

Installation

The macOS installer sets up Python automatically if needed. You’ll still need an OpenAI-compatible LLM endpoint and a Whisper-compatible transcription provider for voice input.

  • The native HUD needs macOS 14+. Liquid Glass is available on macOS 26+; earlier supported versions use translucent material.
  • The combined installer supports Apple Silicon and Intel. No Xcode or Homebrew is needed.
  • This beta is not Developer ID signed or notarized. First setup needs internet access for Python and dependencies.
Python backend ↓Download macOS DMG ↓

Install everything together

Download the DMG, drag Maxi to Applications, and open it. First launch opens Terminal for setup and provider configuration. Or install with one command:

TERMINAL · MACOS
curl -fsSL https://raw.githubusercontent.com/krishnakanthpathi/maxi/main/scripts/install.sh | bash

The installer checks release downloads, preserves existing configuration and memories, and installs the verified Python wheel first, then the compiled native app. The wheel contains no Swift source, and the app contains no Python wheel. The installer starts the Python backend directly, confirms it is healthy, and then opens the HUD. Later launches start the backend and connect the HUD after readiness. Reinstalling restarts the backend to load the new wheel. Your LLM runtime and speech provider are configured separately.

Manual backend installation

For a manual install, first install Python 3.10+ and download the Python wheel above into your Downloads folder, then run:

TERMINAL · MACOS / LINUX
python3 -m venv ~/.maxi/venv
~/.maxi/venv/bin/python -m pip install "$HOME/Downloads/maxi_ai-0.3.0b1-py3-none-any.whl[voice]"
~/.maxi/venv/bin/maxi config wizard
~/.maxi/venv/bin/maxi start

Start the LLM server you configured before sending a request. The wizard sets up your providers. For voice, supply your transcription provider key if it was not configured there.

Install from the DMG

Download the macOS DMG above, open it, and drag Maxi.app into Applications. Open Maxi to set up the separate Python backend wheel and connect the HUD.

Using the older HUD-only ZIP?

Unzip the HUD download and open Maxi.app. If macOS blocks the unsigned application, review it in System Settings → Privacy & Security. Grant Microphone access and Accessibility/Input Monitoring access to the Python or terminal application running Maxi’s shortcut listener.

To build the HUD yourself from source, install Xcode Command Line Tools and run:

TERMINAL · MACOS
xcode-select --install
git clone https://github.com/krishnakanthpathi/maxi.git
cd maxi
python3 -m venv .venv
.venv/bin/python -m pip install -e '.[voice]'
.venv/bin/maxi hud --rebuild
Using Linux or Windows?

The backend and platform shortcuts are supported. On Linux, run the universal installer directly:

LINUX · ONE COMMAND
curl -fsSL https://raw.githubusercontent.com/krishnakanthpathi/maxi/main/scripts/install.sh | bash

On Windows, download the same wheel and use PowerShell:

POWERSHELL · WINDOWS
py -m venv "$HOME\.maxi\venv"
& "$HOME\.maxi\venv\Scripts\python.exe" -m pip install "https://github.com/krishnakanthpathi/maxi/releases/download/v0.3.0-beta.1/maxi_ai-0.3.0b1-py3-none-any.whl[voice]"
& "$HOME\.maxi\venv\Scripts\maxi.exe" config wizard
& "$HOME\.maxi\venv\Scripts\maxi.exe" start

Add your virtual environment’s executable directory to PATH to use the shorter maxi commands below. On macOS/Linux, that directory is ~/.maxi/venv/bin.

THE NATIVE HUD

The original glass pill

The compact pill sits below the hardware notch, and responses appear in a separate glass card. Both show a static ∑ logo, without M morphing or rotation.

The original New Chat, pin, speech and close controls are back on the response card. Hovering pauses auto-hide; spoken responses stay visible until speech finishes. Use the ∑ menu to change position or keep the idle pill visible. Escape dismisses the HUD.

The Python wheel and native macOS app are separate downloads. The installer installs and checks the wheel first, then installs the app.

Responses support Markdown headings, lists, task lists, quotes, links, images, tables, and syntax-highlighted code blocks. Each code block has its own Copy button. HTML blocks and standalone HTML documents also offer Preview: interact with self-contained HTML, CSS, and JavaScript inside the pill, then switch back to Code. Previews use local assets; external scripts and network requests are not loaded.

02 / YOUR MODEL, YOUR CALL

Models & voice

Maxi uses an OpenAI-compatible endpoint for the LLM and a separate Whisper-compatible endpoint for transcription. Use the interactive wizard or set the values directly.

EXAMPLE · LOCAL OLLAMA ENDPOINT
maxi config wizard
maxi config preset ollama
maxi config set llm-url http://localhost:11434/v1
maxi config set llm-model llama3.2
maxi config set voice-key YOUR_PROVIDER_KEY
maxi restart

Choose a model that is installed and available on your endpoint. Presets also include groq and openrouter. Your settings are saved in ~/.maxi/.env.

Provider settings in your .env file
VariablePurpose
OPENAI_BASE_URLYour LLM’s compatible API base URL.
OPENAI_MODELThe model identifier on that endpoint.
OPENAI_API_KEYYour LLM provider’s key.
VOICE_BASE_URLYour transcription API base URL.
VOICE_MODELYour speech transcription model.
VOICE_API_KEYYour transcription provider’s key.
↗
Local model, separate voice provider.

Audio goes to the transcription endpoint you configure. Prompts and captured context go to your LLM endpoint. A local LLM alone does not make transcription local.

04 / KEEP WHAT MATTERS

Chats & memory

New Chat clears recent conversation and stops active voice work. Late responses from the previous chat cannot refill that context. Use it when a conversation has collected assumptions you no longer want the model to use.

Optional LightMem storage is separate. Facts deliberately saved there remain available after New Chat. This beta provides explicit remember, recall, and answer tools; it does not automatically inject memories into every request.

SAVE SOMETHING ON PURPOSE
“Remember: I prefer short, direct answers.”

Check the tool’s confirmation before assuming the fact was saved.

Enable optional LightMem

Install the separate lmem package and make its CLI available to the daemon. If you use Maxi’s virtual environment:

TERMINAL · MACOS / LINUX
~/.maxi/venv/bin/python -m pip install --upgrade lmem
~/.maxi/venv/bin/lmem --help
export PATH="$HOME/.maxi/venv/bin:$PATH"
~/.maxi/venv/bin/maxi restart

To change or remove saved facts, use the management commands supported by your installed lmem version; list them with lmem --help. Maxi’s New Chat action does not delete that memory store.

05 / A LITTLE MORE REACH

Tools & skills

Connect MCP servers to give your model tools for desktop actions. Available actions depend on the servers you install and the permissions you grant. Maxi does not bundle third-party MCP servers or model runtimes.

Create ~/.maxi/mcp_config.json with your server configuration. For a stdio server:

MCP_CONFIG.JSON · EXAMPLE
{
  "mcpServers": {
    "your-server": {
      "command": "/absolute/path/to/server-command",
      "args": ["/absolute/path/to/server.py"]
    }
  }
}

Replace the example paths with an installed server you trust. Place custom Markdown skills in ~/.maxi/skills/. Use the HUD menu to reload skills and MCP connections after changes.

The daemon binds to 127.0.0.1:4848 by default. While it is running, its interactive API reference is at http://127.0.0.1:4848/docs; events use ws://127.0.0.1:4848/ws. Keep the desktop service on loopback.

07 / WHEN SOMETHING GETS STUCK

Troubleshooting

Holding the shortcut doesn’t show anything

Open Maxi.app to start the installed daemon and HUD together. Opening it again brings back the floating pill; you can also choose Show Maxi in the ∑ menu. For a manual installation, run maxi status. If the daemon is stopped, run maxi start. Open Maxi.app or run maxi hud. The HUD and daemon both need to be running.

In System Settings → Privacy & Security, check Microphone, Accessibility, and Input Monitoring permissions for the terminal or Python application that runs Maxi. Restart the daemon after changing permissions. Also check that another application has not claimed your shortcut.

The HUD says it is disconnected

Check maxi status and try maxi restart. The HUD reconnects to the local daemon. If the problem persists, stop the background daemon with maxi stop, then run maxi run in a terminal to inspect startup errors.

Recording works, but I don’t get a response

Verify that the LLM endpoint is running and your configured model exists there. Check your transcription provider URL and key. Run the daemon in the foreground with maxi run after stopping the background instance to see provider errors.

The HUD stays disconnected

Voice, model, and tool actions need the Python backend. Run maxi start; it exits with an error if the API does not become healthy within 30 seconds. Check ~/.maxi/daemon.log and ~/.maxi/launcher.log. The native HUD requires the backend at 127.0.0.1:4848: set HOST=127.0.0.1 and PORT=4848 in ~/.maxi/.env, then run maxi restart and reopen Maxi. API controls wait for a live backend connection.

Memory says the database schema is newer

The selected LightMem executable is older than your memory database. Schema 5 requires LightMem 0.4.0 or later. Upgrade LightMem in the backend environment with ~/.maxi/venv/bin/python -m pip install --upgrade lmem, then check ~/.maxi/venv/bin/lmem --version and reopen Maxi. An older standalone lmem elsewhere on PATH may also need updating. Preserve your existing database; do not reset it or lower its schema version. Saving, recall, and answers use the same global vault.

The model is using context I don’t want

Choose New Chat to reset recent conversation. Previously saved LightMem facts stay separate; manage those through your installed lmem CLI. Starting a chat does not delete saved memories.

A desktop action isn’t available

Check that the relevant MCP server is installed and configured in ~/.maxi/mcp_config.json. Reload MCP connections from the HUD menu, then inspect maxi status for connection errors.

Still stuck? Open an issue ↗ with your OS, Maxi version, and the relevant error. Remove provider keys and personal context from logs before sharing.

08 / SHARE THE LITTLE IDEA

Deploy the website

Import the Maxi GitHub repository into Vercel. Set Root Directory to ./ and Framework Preset to Other. The root vercel.json sets the output directory to website and skips installation and building. No environment variables are required.

The homepage is / and this guide is /docs. Vercel serves the public pages; the daemon and HUD run on each user’s computer.
