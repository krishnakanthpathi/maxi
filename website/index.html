05 / A FEW GOOD QUESTIONS

The little details.

Does Maxi listen all the time?＋

No. Recording starts with the shortcut. You can hold to record or double-tap to lock a hands-free session. There is no wake-word listener. Esc cancels recording and active voice work.

Can everything run locally?＋

The daemon, HUD, and optional memory store run on your computer. Use a local compatible LLM if you prefer. Speech transcription goes to the Whisper-compatible endpoint you configure; a local LLM alone does not make transcription local.

What happens when I start a new chat?＋

New Chat clears recent conversation and stops active voice work. Late responses cannot refill that context. Facts explicitly saved to LightMem stay separate. Automatic memory injection is not included in this beta.

What do I need for the macOS beta?＋

macOS 14+, an LLM endpoint, and a speech transcription provider for voice input. The combined installer sets up Python automatically. Grant Microphone and the appropriate Accessibility/Input Monitoring permissions. The combined DMG supports Apple Silicon and Intel. This beta is not Developer ID signed or notarized. Liquid Glass requires macOS 26+.

Can Maxi control every app out of the box?＋

Desktop actions depend on the MCP servers you connect and the permissions you grant. No third-party MCP server or model runtime is bundled. Linux and Windows have backend support, without a native GUI in this release.
