# ∑ Maxi v0.3.0-beta.1

A native macOS voice HUD for your existing LLM and desktop tools. Hold **Right Option (⌥)** to speak, release to send, and press **Esc** to cancel.

This beta brings Liquid Glass surfaces, ∑ branding, larger bare controls, New Chat, more reliable voice cancellation, and connection recovery after interruptions or sleep.

## Downloads

- `Maxi-0.3.0-beta.1-macos-universal.dmg` — recommended macOS installer for Apple Silicon and Intel, with the ∑ app and mounted-disk icon. First setup installs Python automatically if needed.
- `Maxi-0.3.0-beta.1-macos-universal.zip` — the same combined app without a disk image.
- `install-macos.sh` — one-command installer for the combined app and backend.
- `maxi_ai-0.3.0b1-py3-none-any.whl` — Python backend, bundled sounds, and native HUD source.
- `maxi_ai-0.3.0b1.tar.gz` — sanitized source distribution.
- `MaxiHUD-0.3.0-beta.1-macos-arm64.zip` — unsigned Apple Silicon macOS HUD companion.
- `SHA256SUMS` — checksums for these artifacts.

## Recommended macOS installation

Download the universal DMG, drag Maxi to Applications, and open it. First launch
opens Terminal to download and install the separate backend wheel and voice dependencies and
configure your providers. It downloads a private Python runtime when needed;
you do not need Python, Homebrew, or Xcode preinstalled. Internet is required
for this first setup. The installer starts the Python daemon directly and waits
for a successful health check before opening the HUD. Later app launches start
both the daemon and HUD.

Or use:

```bash
curl -fsSL https://raw.githubusercontent.com/krishnakanthpathi/maxi/main/scripts/install_macos.sh | bash
```

This is an online bootstrap installer, not an offline executable containing
Python. Existing settings and saved memories are preserved. The app is ad-hoc
signed and is not Developer ID signed or notarized. Review the application in
System Settings → Privacy & Security if macOS blocks it.

The backend wheel and native app are separate artifacts. The installer installs
the wheel first, then the app, and verifies API readiness. The app contains both
architectures; clean installation and backend checks ran on Apple Silicon.
Intel runtime behavior has not been tested on an Intel Mac.

The combined app’s build 3 fixes an invisible launch: macOS now opens the HUD
executable directly, while backend setup runs inside the app. Opening or
reopening Maxi presents the idle pill; **Show Maxi** is available in the ∑ menu.
Build 4 also starts the backend directly during installation, so Python starts
without depending on the GUI opening successfully. Build 5 joins the notch and
response into one vertically expanding surface, adds an always-visible Auto-hide
switch, fixes dismissal timers, and animates opening and closing through ∑.
Build 6 restores glass across the connected notch, animates all five bars during
speech playback, and corrects mouse coordinates so the controls accept clicks.
Build 7 restores a separate floating pill below the hardware notch. The pill
expands vertically into its response while keeping a visible gap from the notch.
Build 8 adds GFM tables and task lists, highlighted code with per-block copying,
and interactive local HTML previews. Idle shows only M after an optional 2.5-second
hint; hover rotates the mark and reveals controls. Auto-hide and hint preferences
live in the ∑ menu, and Escape dismisses the pill.

Build 9 restores the original compact glass pill with a separate response card
and static ∑ logos. It removes the compact-M redesign, morphing and spinning;
Markdown, code-copy, HTML previews and backend reliability fixes remain. The
Python wheel and macOS app continue to ship as separate installable artifacts.

## Manual backend installation

Python 3.10+ is required. From the downloaded wheel:

```bash
python3 -m venv ~/.maxi/venv
~/.maxi/venv/bin/python -m pip install "$HOME/Downloads/maxi_ai-0.3.0b1-py3-none-any.whl[voice]"
~/.maxi/venv/bin/maxi config wizard
~/.maxi/venv/bin/maxi start
```

The default local LLM endpoint needs a running compatible server and model. Speech transcription needs a configured provider/key. See the [README](https://github.com/krishnakanthpathi/maxi#readme) for provider configuration and required macOS permissions.

## Launch the macOS HUD

Requires macOS 14+. Unzip the companion archive and open `Maxi.app` after starting the backend. The HUD is unsigned and not notarized; macOS may require approval in System Settings → Privacy & Security.

Alternatively, install Xcode Command Line Tools and build the HUD from a source checkout:

```bash
git clone https://github.com/krishnakanthpathi/maxi.git
cd maxi
python3 -m venv .venv
.venv/bin/python -m pip install -e '.[voice]'
.venv/bin/maxi hud --rebuild
```

Liquid Glass appears on macOS 26+; earlier supported versions use a translucent material fallback. The older `MaxiHUD` ZIP contains only the Apple Silicon HUD companion. Use the new universal DMG/ZIP above for automatic backend setup, or build from source on Intel.

## Context and memory

Choose **New Chat (+)** to clear recent conversation and cancel active voice work. Saved LightMem facts remain separate. Automatic memory injection is not included in this beta.

## Verification

Release packaging checks exclude private configuration, pairing QR codes, runtime history, databases, and build caches. See `SHA256SUMS` to verify downloaded files.
